## Implementation

- Certificate photo recognition runs locally in a bounded, terminated Tesseract worker with English/Georgian data. Executable worker/WASM assets are self-hosted; only public language data downloads from the provider CDN. JPEG/PNG/WebP size and pixel limits, timeout, confidence filtering, explicit editable review checkbox, manual fallback. No image, raw OCR text, owner name, ID or address is saved or uploaded. Only confirmed vehicle fields and an optional plate pass the existing garage whitelist. VIN-photo decoding uses a deliberately partial local manufacturer/WMI lookup; model/year are not guessed from a WMI or cyclic year code. The existing separately selected NHTSA VIN lookup remains available with its existing disclosure. Unknown/ambiguous fields remain blank. Real-world photo accuracy and older plate formats still require user verification.
- New requests can opt into `searchScope: city` with `PARTFLOW_CITY_EXPANSION=true` in the Pages build. At 15 minutes from the server creation timestamp, an open request without `acceptedOfferId` matches other cities. No background writes or scheduler/billing dependency. Shop matching refreshes locally every second; offer creation is enforced with Firestore server time. Customer-only manual expansion is immediate and timestamp protected. Acceptance/closure stops expansion atomically through the existing order workflow; chatting/viewing do not change eligibility. Prior offers are retained. Legacy requests retain their original nationwide behavior. Existing specialty-based read permissions are preserved: city routing is a matching/offer eligibility rule, not a new confidentiality boundary.
- Read-only infrastructure collectors, configurable thresholds, an hourly opt-in GitHub workflow, explicit unknown/stale states, quota/network UX and a backup/recovery runbook. This is not a hard spending cap or automatic failover.
- Pages publishing now depends on the complete reusable regression workflow.
